메시지를 의도별로 정리하고, 자신의 어투로 답장 초안을 작성하고, 브랜드 딜과 예약, 링크 묶음을 정돈된 상태로 유지해요 — 모두 휴대폰에서, 중간에 서버 없이.

🌐 10개 언어

모든 걸 직접 운영하는 크리에이터를 위해 만들었어요

인플루언서와 콘텐츠 크리에이터

브랜드 제안, 협업 요청, 팬 메시지가 동시에 들어와요. InfAssist가 각각에 태그를 붙여서 유료 작업을 쉽게 알아볼 수 있어요.

브랜드 딜을 협상하는 크리에이터

브랜드 협업을 첫 제안부터 서명된 계약, 전달 증빙, 결제까지 — 흩어진 메모 대신 하나의 딜 보드에서 추적하세요.

1인 크리에이터와 소규모 팀

매니저도, 에이전시도, 서버를 위한 월 요금도 필요 없어요. 모든 게 휴대폰에서 돌아가고 비공개로 유지돼요.

무엇을 하나요

에이전시의 복잡함 없이, 크리에이터의 일상적인 받은 편지함에 필요한 모든 것.

의도별로 정리

팬 메시지, 브랜드 딜, 협업, 예약 요청 또는 스팸 — 기기에서 자동으로 태그가 붙어요.

당신의 어투로 초안 작성

페르소나를 고르면 모든 답장이 그 어투의 초안으로 시작해요. Pro와 직접 준비한 OpenAI 키가 있으면 AI가 발신자의 언어로 초안을 작성해요.

딜, 처음부터 끝까지

제안부터 서명까지의 보드, 증빙 링크가 있는 전달물, 결제와 결과, 그리고 상대방에게 보내는 확인 이메일.

예약과 캘린더

예약 요청을 실제 약속으로 바꿔서 아무 캘린더 앱으로나 보내세요.

링크 묶음

링크 세트를 한 번 저장하고, 한 번의 탭으로 답장에 추가하고, 얼마나 자주 보냈는지 확인하세요.

어시스턴트Pro

“답장 안 한 DM이 몇 개예요?” 또는 “어떤 전달물이 늦었나요?” 라고 물어보세요 — 휴대폰에서 바로 답해줘요. Pro는 직접 준비한 키로 자유로운 질문도 추가해줘요.

통제권은 당신에게 있어요

정리해요

모든 메시지에 의도 라벨이 붙어서 브랜드 제안이 팬 댓글 아래 묻히지 않아요.

초안을 써요

당신의 페르소나 어투로 답장이 준비돼요. 수정하거나, 링크 묶음을 추가하거나, 버리세요.

당신이 보내요

앱이 메일 앱이나 Instagram을 텍스트가 준비된 채로 열어요. 직접 보내기를 누르기 전까지는 아무것도 전송되지 않아요.

실제로 보기

화면에는 가상의 예시 데이터가 표시돼요.

데이터는 당신의 휴대폰에 남아요

InfAssist는 저희 소유의 서버가 없어요. 모든 것이 앱 안의 데이터베이스에 있어요.

개인정보 처리방침 읽기

  • 만들어야 할 계정도, 가입도 없어요.
  • 앱 안에는 광고도, 분석 도구도, 추적도 없어요.
  • 데이터는 직접 준비한 키로 AI 초안을 요청할 때만 OpenAI로 전송돼요. Android 결제는 Google Play에서 처리하며 iOS 구독은 아직 제공되지 않아요.
  • 앱을 삭제하면 데이터도 사라져요.

질문

지금 사용할 수 있나요?

아직이에요. 첫 버전을 App Store와 Google Play에 출시하기 위해 준비 중이며, 출시되면 이 페이지에서 두 곳 모두로 연결돼요.

제 Instagram이나 이메일에 연결되나요?

이번 버전에서는 아니에요. 답장은 메일 앱이나 Instagram으로 전달되고 당신이 직접 보내기를 눌러요. 실제 받은 편지함에 연결하려면 서버가 필요한데, InfAssist는 의도적으로 서버가 없어요.

OpenAI 키가 필요한가요?

AI가 작성한 초안과 어시스턴트에 대한 자유로운 질문에만 필요하며, 둘 다 Pro 기능이에요. 키가 없으면 앱은 기본 제공 답장 템플릿과 로컬 답변을 사용해요.

제 데이터는 어디에 저장되나요?

휴대폰 안의 데이터베이스에요. OpenAI 키는 시스템의 보안 저장소(iOS Keychain / Android Keystore)에 있어요.
