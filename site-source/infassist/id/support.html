Pertanyaan

Bagaimana cara menghapus data saya?

Semuanya disimpan di dalam aplikasi di ponselmu. Menghapus aplikasi menghapus semuanya. Di dalam aplikasi kamu juga bisa menghapus akun, kesepakatan, bundel tautan, dan kunci OpenAI-mu satu per satu (Profil).

Pembelian Pro saya tidak muncul.

Buka Profil dan ketuk “Pulihkan pembelian”. Pembelian terkait dengan Apple ID atau akun Google-mu.

Draf AI tidak muncul.

Draf AI membutuhkan Pro dan kunci API OpenAI milikmu sendiri dengan kredit di akun OpenAI-mu. Tanpa itu, templat bawaan yang digunakan.

Bagaimana cara mengganti bahasa?

Gunakan menu bahasa di bagian atas aplikasi. Secara default mengikuti bahasa ponselmu.
